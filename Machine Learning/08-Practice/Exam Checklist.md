# Exam Checklist

- [ ] Can derive least squares, logistic gradient, softmax-CE gradient ([[Matrix Calculus Cheatsheet]])
- [ ] Can compute LDA / perceptron / one-vs-rest boundaries by hand ([[Linear Models for Classification]])
- [ ] Margin, KKT, dual of SVM; compute a kernel matrix ([[Support Vector Machines]], [[Kernel Methods]])
- [ ] Forward + backward pass of a 2-layer net on paper ([[Backpropagation]])
- [ ] One EM iteration for a GMM ([[Gaussian Mixture Models and EM]])
- [ ] Naive Bayes counting with Laplace smoothing ([[Naive Bayes]])
- [ ] d-separation queries ([[Probabilistic Graphical Models]])
- [ ] ELBO and mean-field update ([[Variational Inference]])
- [ ] Link prediction scores and GNN layer ([[Link Prediction]], [[Graph Neural Networks]])
- [ ] Definitions in [[ML Glossary]]
- [ ] Cheat sheet: [[8-semester/ML/cheetsheet|Linear model cheat sheet]]; worked examples: [[8-semester/ML/Examples|Examples]]

> [!tip] Strategy
> Write dimensions of every matrix next to it. Most mistakes are transposes (rows vs. columns as samples).
