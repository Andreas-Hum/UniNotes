# ML Glossary

**Activation** — non-linear function in a unit → [[Activation Functions]]
**Attention** — weighted lookup over values → [[Transformers]]
**Backprop** — gradient computation by chain rule → [[Backpropagation]]
**Batch / mini-batch** — samples per gradient step → [[Gradient Descent]]
**Bias (model)** — error from wrong assumptions → [[Bias-Variance Tradeoff]]
**Bias (parameter)** — intercept $b$
**Calibration** — predicted probabilities match frequencies
**Class imbalance** — skewed label distribution → [[Data Preprocessing]]
**Convex** — any local min is global → [[Calculus and Optimization]]
**Cross-entropy** — loss between distributions → [[Information Theory]]
**Curse of dimensionality** — data sparse in high dimension → [[k-Nearest Neighbors]]
**Data leakage** — test info enters training → [[Common Pitfalls]]
**Embedding** — dense vector for discrete object
**Epoch** — one pass over the training set
**ELBO** — evidence lower bound → [[Variational Inference]]
**F1** — harmonic mean of precision and recall → [[Model Evaluation and Metrics]]
**Feature** — input variable → [[Feature Engineering]]
**Fine-tuning** — continue training a pretrained model
**Generalization** — performance on unseen data
**Gradient** — vector of partial derivatives
**Hyperparameter** — set before training (η, λ, depth, k)
**Inductive bias** — assumptions that let a learner generalize
**Kernel** — similarity function → [[Kernel Methods]]
**KL divergence** — asymmetric distribution distance
**Label** — target value
**Latent variable** — unobserved variable → [[Gaussian Mixture Models and EM]]
**Learning rate** — step size η
**Logit** — pre-sigmoid/softmax score; log-odds
**Loss function** — quantity minimized in training
**MAP / MLE** — estimation principles → [[Probability for ML]]
**Margin** — distance from boundary to nearest point → [[Support Vector Machines]]
**Overfitting** — memorizing noise → [[Overfitting and Regularization]]
**Perceptron** — linear threshold unit → [[Linear Models for Classification]]
**Posterior / Prior** — [[Bayesian Inference]]
**Precision / Recall** — [[Model Evaluation and Metrics]]
**Regularization** — constraints to reduce overfitting
**Residual connection** — $y=F(x)+x$ → [[CNN]]
**ROC curve** — TPR vs. FPR across thresholds
**Softmax** — normalizes scores to probabilities → [[Logistic Regression]]
**Sparsity** — mostly zero weights/features (L1)
**Underfitting** — model too simple
**Variance (model)** — sensitivity to training set
**VC dimension** — capacity of a hypothesis class
**Weight decay** — L2 penalty applied in the update
