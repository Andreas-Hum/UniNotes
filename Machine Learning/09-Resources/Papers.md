# Landmark Papers

Read in roughly this order. Links go to arXiv where available.

## Classical ML (pre-arXiv, search by title)
- Rosenblatt (1958) *The Perceptron*
- Dempster, Laird, Rubin (1977) *Maximum Likelihood from Incomplete Data via the EM Algorithm*
- Rumelhart, Hinton, Williams (1986) *Learning representations by back-propagating errors*
- Cortes & Vapnik (1995) *Support-Vector Networks*
- Hochreiter & Schmidhuber (1997) *Long Short-Term Memory*
- Breiman (2001) *Random Forests*; Friedman (2001) *Greedy Function Approximation: A Gradient Boosting Machine*
- Koren, Bell, Volinsky (2009) *Matrix Factorization Techniques for Recommender Systems*

## How to read papers
Abstract → figures → conclusion → method → experiments. Find new papers on [arXiv](https://arxiv.org/) and [Hugging Face Papers](https://huggingface.co/papers) (Papers With Code shut down in July 2025 and now redirects there).
