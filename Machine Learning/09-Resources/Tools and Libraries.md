# Tools and Libraries

| Area | Tools |
|---|---|
| Numerics | [NumPy](https://numpy.org/doc/stable/), SciPy, JAX |
| Data | [pandas](https://pandas.pydata.org/docs/), Polars, DuckDB |
| Classical ML | [**scikit-learn**](https://scikit-learn.org/stable/user_guide.html), XGBoost, LightGBM, CatBoost |
| Deep learning | [**PyTorch**](https://pytorch.org/tutorials/), TensorFlow/Keras, JAX/Flax, PyTorch Lightning |
| Vision | [torchvision](https://pytorch.org/vision/stable/index.html), timm, OpenCV, Ultralytics |
| NLP / LLM | [Hugging Face Transformers](https://huggingface.co/docs/transformers/index), tokenizers, PEFT, TRL, vLLM |
| Probabilistic | [PyMC](https://www.pymc.io/), Stan, Pyro, NumPyro, GPyTorch |
| Graph | [PyTorch Geometric](https://pytorch-geometric.readthedocs.io/), DGL, NetworkX |
| Recommenders | implicit, surprise, LightFM, [RecBole](https://recbole.io/docs/), TorchRec, FAISS |
| RL | [Gymnasium](https://gymnasium.farama.org/), Stable-Baselines3, CleanRL |
| Time series | statsmodels, Prophet, sktime, Darts |
| Viz | matplotlib, seaborn, plotly, TensorBoard |
| Experiments / MLOps | Weights & Biases, MLflow, DVC, Optuna |
| Notebooks | Jupyter, [Google Colab](https://colab.research.google.com/), Kaggle Notebooks |
