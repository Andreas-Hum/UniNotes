ML Playgrounds

Poke the models and watch them react. Every tab has a "Try this" box with experiments to run.

Linear SVM: the widest street

Click to add points (pick the class first), drag points to move them. The solid line is the decision boundary, dashed lines are the margins, circled points are support vectors.

Try this:
1. Drag a point far from the boundary. Does the line move? (Only support vectors matter.)
2. Add one orange point deep inside the blue cloud, then slide C from high to low.
3. Make C tiny: the street gets wide and ignores outliers.

k-means clustering

Click to add points. Press Step to run one assign + update iteration and watch the centroids (big markers) move.

Try this:
1. Make 3 blobs and run with k=3 several times using "New random centroids". Do you always get the same answer? (Local minima!)
2. Draw two long thin parallel lines of points. Why does k-means cut them the wrong way?
3. Watch SSE: it never goes up between steps.

Gradient descent on a loss surface

Click anywhere to start the optimiser there. Darker = lower loss. The path shows every step.

Try this:
1. Bowl + gradient descent: raise the learning rate until it zig-zags, then until it diverges.
2. Same start, switch to momentum: fewer zig-zags.
3. Rosenbrock: compare all three optimisers.
4. Two minima: which minimum you reach depends on where you start.

Attention: a query looking at keys

Drag the query (★) and the keys (circles). Weights are softmax(q·k / √d / T). The output is the weighted mix of the value colours (big square).

Try this:
1. Move the query close to one key: its weight dominates.
2. Lower the temperature: attention becomes almost one-hot ("hard"). Raise it: weights become uniform.
3. Drag the query far from the centre: the dot products grow and the softmax saturates – this is why we scale by √d.

A tiny neural net learning XOR

A 2 → H → 1 network with tanh hidden units, trained live by gradient descent on the XOR points. The background shows the predicted class.

Try this:
1. Set H = 1: the net can only draw one line, and XOR needs two. It never solves it.
2. H = 2 sometimes gets stuck – press "New random weights" a few times.
3. Learning rate at max: watch the loss curve jump around.
