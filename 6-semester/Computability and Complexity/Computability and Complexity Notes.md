The encoding of the data matters, we need to careful on what we measure

We are mostly concered with so called decision problems

general format yes/no qeustions over a (typically infinite) set of inputs

we abstract away much, we only consider sequences of symbols as inputs
- A number is encoded in binary or decimal
- a graph is encoded by (a linearization) of its adjacency matrix
- a program is given by its source code
